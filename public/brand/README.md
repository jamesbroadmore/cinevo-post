## Type

Wordmark and headlines: **Montserrat ExtraBold**, all caps.  
UI / body: Montserrat Regular and Medium.

## What’s in the folder

- `CINEVO_Brand_Guidelines.pdf` — 12-page usage guide
- `svg/` — vector masters (mark, stacked, horizontal, app icon, color + mono)
- `png/` — raster masters at 1024px plus favicon sizes (32–512)

## Rules of thumb

1. Stacked lockup is primary. Horizontal is for short, wide spaces.
2. Keep clear space equal to the cap-height of the C.
3. Do not recolor facets, rotate the mark, or substitute the typeface.
4. On cheap print, use the ink monochrome lockup.
5. The app icon lives on night purple. Do not put the wordmark inside it.
